# Read-me-file
This project does not include a custom-trained model due to performance challenges encountered during our attempts at data gathering and fine-tuning. Although we built a parallel corpus and fine-tuned models for both translation and assessment tasks, the results were suboptimal, showing inconsistencies in translation accuracy and assessment reliability. Consequently, we shifted to leveraging pre-trained Large Language Models (LLMs) through prompt engineering to generate personalized exercises and evaluate translations. This approach improved performance and allowed us to focus on delivering an adaptive learning experience, ensuring that the system meets educational goals effectively.
